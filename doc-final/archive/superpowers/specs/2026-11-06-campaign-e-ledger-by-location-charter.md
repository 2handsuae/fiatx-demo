## §0 目标（三句话）

1. **资产按「钱在哪儿」开户，负债权益只记「是谁的」。** 每个真实银行账户 / 钱包在账本里是一个现金户；运营户拆成「公司现金·运营」+「公司权益」（本钱留在公司权益）；结算在途、LP 前厅回到资产；收入科目脱离费用钱包；新增开支三户、应收 LP 交货、托管短缺待补。对账从「一个钱包对两三个负债权益科目」变成「一个现金户对一张对账单」。
2. **七种订单 + 调账单全部记到新科目，行为不变。** 四道门、腿即资金单、两阶段锁定、资金单状态机、外部参考号、在途识别、处置家族与审批一概不动。改的是每条腿「记到哪个科目」，不是「什么时候记、记多少」。
3. **对账拆成两道。** 对外：现金户 vs 对账单（账和世界一不一致）；对内：现金户 vs 应付加暂扣（自己的账一不一致）。客户钱包多一个对内差额；钱包标签、跨外部标记、过滤码集、「钱包角色→科目」映射表全部退役。

判断标准照项目总纲 §1；禁做照 §2。

- 三波都动钱动账本，**plan 点名评审升档**；终审、变异测试不降档（项目总纲 §6 派发分层表）。
- 转账码：**现有码号一律不改**（语义随科目变，注释改写）；新码从 **88** 起（87 已被付款单占）。科目码 u16 一经分配不可改；新码见附录 A。
- 常量改名（若岔口 1 定改）走最低档机械替换，但**改前 grep 清点、改后复核数量**（纪律 5）。
- 派 subagent 带项目总纲 §0–§5 要点。
- 业主待办：岔口 1、3 到波一 spec 一句话；岔口 5 核一眼；收官确认科目表导出。

**天平与不变量**

- 客户本：Σ(1) + Σ(2) = Σ(100) + Σ(101)，按币种。
- 公司本：Σ(50) + Σ(51) + Σ(300..302) = Σ(200) + Σ(210..212) + Σ(150)，按币种。
- 不负：全部户。借方户 `credits_must_not_exceed_debits`，贷方户 `debits_must_not_exceed_credits`。
- **公司权益 ≥ 公司现金·运营 恒成立**：差额 = 其他公司现金户 + 应收 LP + 未结转开支 − (已扫入运营户但未结转的收入)。最后一项靠 §4 岔口 5「扫费同额结转」钉为零，于是现金闸（出款前查公司现金·运营）顺带保住公司权益不负。谁给公司权益加一条不经现金的借方分录，这个保证就破了——写进交付合同。
- 逐客户控制报表（不是账本结构）：客户现金·该客户 + 短缺待补·该客户 = 应付 + 暂扣，逐客户算；法币改母账户模式时退化为总数，账本不改。
