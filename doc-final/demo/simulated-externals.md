# 什么是真的、什么是模拟的（simulated-externals）

> 给演示者兜底、也给 agent 划界：**模拟件不是生产接口，禁止对它做任何加固**。

## 一张表

| 外部件 | 真/假 | 假在哪 | 怎么触发 |
|---|---|---|---|
| **账本（TigerBeetle）** | ✅ **真** | 真复式记账、真恒等式——这是演示的地基，不是模拟 | 每笔交易自动逐腿记账 |
| 状态机/审批/RBAC/审计 | ✅ 真 | 全部真实执行 | 页面操作 |
| **Sumsub 合规** | 🎭 模拟为主 | `SUMSUB_MOCK_MODE=true`：裁决由管理台 ⚡ 按钮喂（10 种原子裁决：通过/拒绝/制裁命中/PEP/要求补料/慢 case/SLA 超时…）。Alice 挂了真沙盒 applicant，其余客户是确定性 mock id | 管理台详情页 ⚡ Simulation 面板 |
| **链上** | 🎭 假 | 无真实链：txHash 是伪造值（已知瑕疵：0x 以太坊格式，对 TRON 网络不真实——登记在案）；确认/失败由模拟端点触发 | ⚡ 面板 / demo 脚本 |
| **银行（法币）** | 🎭 假 | 无真实银行通道：入账/出账确认由模拟端点触发；对账的"银行对账单"由 recon:demo 脚本铸造 | ⚡ 面板 / recon 脚本 |
| **托管方 / 银行回单（内部划转腿）** | 🎭 假 | 腿一提交，模拟托管方就往对账单里写出方 OUT、入方 IN 两行并增减当日收盘；铺场脚本重铸时不重复；铺场前不得有在途划转 | 资金单 ⚡ SUBMIT |
| **时间** | 🎭 可拨 | SLA 到期不必干等：`Simulate SLA Timeout` 按钮把截止时间拨到过去 | 各域详情页按钮 |

## 讲给观众的一句话

"钱和账是真的，外部世界是遥控的——所以我们能当场演出制裁命中、银行退回这些现实里等不来的场景。"

## 给 agent 的一句话

模拟端点只在 `SUMSUB_MOCK_MODE=true` 时注册；它们的"不严谨"（可重复喂、无鉴权细节）是**演示功能不是缺陷**，禁止加固、禁止登记为技术债。
