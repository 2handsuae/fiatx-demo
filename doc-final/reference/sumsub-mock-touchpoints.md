# Sumsub mock 触点登记册（对手方层）

> 建册 2026-10-22（对手方波一：提现地址簿）｜ 同日续登 ⑤–⑧（对手方波二：充值来源归因 / 名录档案 / TR 阈值与认领 / 认领解锁）｜ 缺口编号 = `reference/sumsub-services-needed.md` 的小节号（#1 归因 / #2 所有权验证链支持 / #3 筛查触发条件 / #4 TR 验证规则与生态未激活 / #5 TR 阈值是否支持关联累计）
> 用途：业主要做 mock↔sandbox 切换时的地图——哪些能力是「站在 Sumsub 一侧」的 mock、真 Sumsub 对应哪项服务、切换时动哪一刀。
> 范围：**本册只收对手方层**（地址归因 / 地址风险筛查 / 钱包签名验证；波二的来源归因喂 / VASP 名录档案 / TR 阈值与已知来源 / 认领解锁）。既有总开关 `SUMSUB_MOCK_MODE` 与裁决 ⚡ 全家族（`admin/sumsub/simulate/*`）不在此重登，见 `demo/simulated-externals.md`。

## 三、定位
