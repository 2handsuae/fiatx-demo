## 6. 三流程能力入口（索引版）
- 充值流程入口：`入金申请 -> 风控校验 -> 到账确认 -> 入账`
- 兑换流程入口：`报价 -> 下单 -> 路由 -> 执行 -> 成交回报 -> 清算入账`
- 提现流程入口：`申请 -> 风控校验 -> 放行 -> 链上/银行出款 -> 结果通知 -> 对账`
- 说明：详细节点到能力映射改由后续 `流程映射专用文档` 维护，本目录仅保留入口。
