# 统一清分条目类型与金额逻辑计划

- 修改 `src/config/manifests/clearing-templates.manifest.ts`：
  - 将 `lineType: 'OUT'` 改为 `lineType: 'OUTGOING'`。
  - 确保所有条目使用 `INCOMING`, `OUTGOING`, `FEE` 标准类型。

## 2. 重构清分触发逻辑
- 修改 `src/modules/clearing-settle/clearing/clearings.service.ts`：
  - 移除 `amountSource.includes(...)` 等模糊匹配逻辑。
  - 改为基于 `lt.lineType` 的直接映射：
    - `FEE` -> `feeAmount`
    - `INCOMING`/`OUTGOING` -> `netAmount`

- 验证提现审批流程，确保生成的 `ClearingLine` 金额与类型完全对应。
