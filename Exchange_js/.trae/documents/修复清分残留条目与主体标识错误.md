# 提现清分逻辑精简修复计划

## 1. 精简清分模板
- 修改 `src/config/manifests/clearing-templates.manifest.ts`：
  - 针对 `WITHDRAWAL_STANDARD_V1` 模板，删除多余的条目。
  - 最终只保留两条规则：
    1. `lineNo: 1, lineType: 'FEE', partyType: 'PLATFORM'` (手续费)
    2. `lineNo: 2, lineType: 'OUTGOING', partyType: 'CUSTOMER'` (出金净额)

## 2. 数据库配置同步
- 运行 `npx ts-node prisma/seed.ts`：
  - 更新数据库中的 `ClearingLineTemplate`，确保旧的多余规则被覆盖或清理。

## 3. 验证修复效果
- 模拟一笔提现审批。
- 检查 `Clearing` 详情：
  - 确认 Header 的 `outAmount` 为总额，`inAmount` 为 0（提现无入金）。
  - 确认 `ClearingLine` 仅有两条：FEE 和 OUTGOING。
