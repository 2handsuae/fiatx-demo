# 系统初始化配置中心重构计划

## 1. 拆分 acct-config.data.ts
- 创建 `src/config/manifests/events.manifest.ts`，存放会计事件定义。
- 创建 `src/config/manifests/journal-templates.manifest.ts`，存放凭证模板定义。
- 删除原 `src/config/manifests/acct-config.data.ts`。

## 2. 从 seed.ts 提取静态数据
- 创建 `src/config/manifests/coa.manifest.ts`，提取会计科目表数据。
- 创建 `src/config/manifests/assets.manifest.ts`，提取基础资产（AED, USDT等）数据。
- 创建 `src/config/manifests/clearing-templates.manifest.ts`，提取清分模板数据。

## 3. 重构 seed.ts 落地逻辑
- 修改 `prisma/seed.ts`，移除内部硬编码的数据，改为从 `src/config/manifests/` 下的所有文件导入。
- 保持 `seed.ts` 的 `upsert` 逻辑不变，确保初始化幂等。

## 4. 适配业务逻辑
- 更新 `src/modules/accounting/acct-events/acct-config.service.ts` 的导入路径，适配拆分后的文件。
- 检查其他引用了原配置文件的模块并修复。

## 5. 验证
- 运行 `npm run build` 确保无路径错误。
- 运行 `npx ts-node prisma/seed.ts` 确保数据库初始化依然成功。
