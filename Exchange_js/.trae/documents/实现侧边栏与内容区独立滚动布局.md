# 优化布局实现独立滚动区域

## 1. 布局结构调整
*   将最外层容器 [CustomerDashboardLayout.tsx](file:///Users/songshengwei/Documents/trae_projects/Exchange_js/client-web/src/components/CustomerDashboardLayout.tsx) 的高度固定为 `h-screen`，并设置 `overflow-hidden`，防止整页滚动。
*   确保侧边栏 `aside` 区域高度撑满且拥有独立的滚动条（如果菜单项过多）。
*   主内容区域（右侧）设置为 `flex-1` 且 `h-full`，其内部的 `main` 容器设置 `overflow-y-auto`，实现独立滚动。

## 2. 具体代码修改
*   修改 `CustomerDashboardLayout.tsx` 的最外层 `div` 类名，从 `min-h-screen` 改为 `h-screen overflow-hidden`。
*   优化侧边栏的定位逻辑，确保在所有屏幕尺寸下，左侧菜单和右侧详情展示的滚动条互不干扰。
*   调整 Header 的定位，使其在右侧滚动区域上方保持固定。
