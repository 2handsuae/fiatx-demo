# 交付清单（delivery-checklist）

Last Updated: 2026-09-01 ｜ 跨前后端，写代码时读 ｜ 闸门本身的定义在 `CLAUDE.md §7`，本文不复述

## 怎么用

**按左列扫，不按右列读。** 一个任务通常只命中 2–3 行——没命中的不是"跳过了"，是**根本没触发**。

`plan` 的 Global Constraints 从此写两行，不要重抄本表：

```
- 通用交付清单见 rules/delivery-checklist.md，全部适用
- 本轮特有：<只写这一轮独有的约束>
```

**判定"这是小任务、可以省"的不是执行者，是 plan。** 执行时"省一条"永远是省事的那个选项，而且越累越想省；plan 是在还有全局视野、还没被这个任务烦到的时候写的。`CLAUDE.md §6` 已要求任务开场列「本任务做 / 不做」——对称地，**任务收尾列「本任务过哪几条」，由 plan 写死**。

## 清单

| 触发 | 必须做 | 漏了会怎样（都发生过） |
|---|---|---|
| **任何持久状态变化** | 写审计。`AuditLogsService` 经 DI 注入、写在编排层；人为动作 `recordByActor`、系统动作 `recordSystem`；**每次带显式 `requestId`** | 漏 `requestId` 会被静默去重，这条日志直接消失 |
| **新增审计动作码** | 出生即冻结四属性（含义 / actionDomain / correlationMode / 特有必填），`assertActionSpec` 写入时机器校验 | "先上车后补票"的码后来没人说得清它记的是什么 |
| **新状态 / 新结局** | 主体服务的**显式迁移表加一条边**，非法跃迁显式拒绝；顺带回答**要不要计时（SLA）** | 绕表直写 = 状态机不再是真相；忘了计时的状态会永远挂着没人管 |
| **动了钱** | workflow **同步直调** `AccountingService`（禁挂事件），失败即流程失败、状态不得推进；资金单 1:1 镜像；不新增科目 | 记账挂事件 = 同步 ACID 变最终一致；账实不一致时对账演示当场垮 |
| **该走 maker-checker** | 走 `ApprovalsService` 正门 | 自己造审批 = 门可绕，铁律② |
| **新增 maker-checker 审批策略** | 往 `scripts/verify-rbac.ts` 的 `MAKER_GROUP_BY_POLICY` **加一行**（人工维护表，S5 只遍历它） | 表外策略不受自批死锁闸保护——调账单就是这么漏的（2026-09-01） |
| **新增权限组** | 必须同时出现在**四处**：`PermissionGroup` 联合类型 ｜ 至少一条 `route()` ｜ `ACTION_BUCKET_CATALOG` 的某个桶 ｜ 至少一个职务持有 | 少一处 = 演示里点不到。调账单曾只齐两处：没人能开单、自定义角色 UI 也勾不到 |
| **新增 admin 端点** | `rbac.catalog.ts` 用 `route()` 登记 + `npm run db:base:sync` + **重启后端** | 只 seed 不重启 = 前端 403。SUPER_ADMIN 走内存不受影响，所以自测时看不出来 |
| **新增业务动作** | **前端要有入口** | 演示者点不到 = 这个功能不存在 |
| **退役业务动作** | **前端入口同步删** | 幽灵按钮：点得到、点了没反应。第一幕一次清掉 13 条幽灵路由 + 30 个死权限组 |
| **改了交易三域任一**（充值/提现/兑换） | **问另外两个域一不一样** | BACKLOG 里 14 条是这么来的。典型：tipping-off 防线只在充值域落实，提现域裸奔 |
| **新字段 / 新状态到客户面** | 当场决定**客户看不看得到**（tipping-off 白名单） | 藏错了客户少看见一条；露错了是刑事风险，代价不对称 |
| **涉及金额** | 最小单位存、展示层换算 | 对账 Cases 页把「分」当「元」显示 |
| **对外识别** | 用业务键（`...No` / `code`），管理台不暴露 UUID | 铁律⑥。单号是演示可见物 |
| **新事件** | 先登记 `src/common/events/domain-events.constants.ts` 才能用 | 一处看不全全部事件，跨模块编排就成了盲区 |
| **改 schema** | 新增迁移文件（保证空库能建起；**不写 backfill / 兼容层**，改完 = reset 重铺） | 空库建不起来，别人拉了代码跑不动 |
| **改页面或种子** | 同步 `demo/data.md` + `demo/script.md` 对应步骤 | 演示时讲错。`data.md` 的生成区由 `demo:all` 自己写，别手改 |
| **改了前端** | 起 preview 渲染 + **截图**验证 | tsc 过不算数。曾有一批单测全绿、起 preview 一看逮到 3 个真 bug |
| **每轮收尾** | 文档分层收口（`CLAUDE.md §9` 报告动了哪层）+ `CHANGELOG` 一行 + `BACKLOG` 销账 | 下一轮没人说得清这版比上版多了什么 |

## 两条永不豁免

即使 plan 判定"这是小任务"，这两条也不许省——历史上就它俩真逮到过东西：

1. **改了前端行为 → 必须截图。** 单测和 tsc 对渲染结果一无所知。
2. **动了钱 → `verify:coa`。** 账实一致是对账演示的前提，错了不当场发现就在演示当天暴露。

关于 ② 有一条 2026-09-01 挣来的读法：**注资/期初缺一笔时，表现是「恒等式全过、只有负余额断言红」**——恒等式对**差额**成立，不管起点是不是 0。所以负余额断言是这类"起点缺一笔"事故的**唯一**探针，不能因为四条恒等式绿就放行。
