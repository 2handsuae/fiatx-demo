## 0. 一句话定位

**一笔真实的资金移动 = 一张资金单。** 链上转账、银行指令、平台内部搬钱，每一次物理移动都有一张执行单记录它走到哪一步了。全系统只有这一张表（历史上七张表三合一），充值、提现、兑换的"腿"都是它。

## 1. 业务叙事

最重要的一件事：**账本记"钱的归属变了"，资金单记"钱的物理移动走到哪了"——两者一一镜像，对账才有锚。** 账本说这笔钱现在该是谁的；资金单说搬运它的那辆车开到了哪里。第六幕的在途识别，就是拿"外部已见、内部未落"的行去资金单里找"还在路上的车"。

**出生地不同，起点就不同。** 四套迁移表按"方向 × 资产"分治：链上入金——看到就已经在链上了，出生即"已提交"；法币入金——银行到账了我们才知道，出生即"已确认"；出金（提现/兑换/处置腿）——从"已创建"走全程。同一张表、四种走法，哪种单走哪条路查表可知。

**腿的语言。** 充值 = 1 条入金腿，处置时额外挂腿（没收=第 2 腿、退回=第 3 腿、上缴=第 4 腿）；提现 = 本金腿 + 费腿（费腿失败不拖本金）；兑换 = 4 条腿。**重试不改旧单**——失败的腿以新的尝试号重建一张新单，旧单留在原地作历史；每一次尝试都可追溯。

**资金单自己也是状态机。** 处置腿记完账、订单落了终态之后，**腿本身也必须收口到"已清算"**——真机逮到过一张腿永远停在"已确认"的案例（账是对的、视图是错的），此后有守则测试盯着：每条处置弧的结算函数必须收口腿状态，漏写即红。

**外部参考号。** 腿首次到达"已确认"时铸参考号（链上=交易哈希、法币=银行参考号；演示环境为铸造值），消费方统一经一个读法取号，三个交易域不再各自推导。

## 2. 状态机（一套全集，四套走法）

全集：`CREATED → SUBMITTED → CONFIRMING → CONFIRMED → CLEARED`，旁支 `FAILED / TIMEOUT`

| 走法 | 路径 |
|---|---|
| 链上入金 | `SUBMITTED → CONFIRMING → CONFIRMED → CLEARED`（无超时旁支） |
| 法币入金 | `CONFIRMED → CLEARED`（单跳） |
| 链上出金 | 全 5 步 + 失败/超时旁支 |
| 法币出金 | `CREATED → SUBMITTED → CONFIRMED → CLEARED`（跳过链上确认段） |

逐步推进、不跳步；内部搬运腿（兑换腿、充值处置腿）按出金表走。

| 动作 | 谁发起 | 要点 |

## 4. 演示脚本（腿视角）

1. 资金单列表：按类型/状态筛，看 External Ref 列（链上哈希 vs 银行参考号）
2. 任一在途腿：详情页 ⚡逐步步进 → 观察订单侧联动（腿确认、订单落终态、腿收口清算）
3. 演一次异常弧：对没收腿点 ⚡失败 → 看工作流接住、解锁、回到待处置——"红按钮不是事故，是素材"
4. 第六幕连线：孤儿外部行 ↔ 非终态资金单的在途认领

## 5. 关键技术节点（≤30 行）

- **处置动词** `disposition.service.ts → DispositionService`（地基站 2026-08-26）：带账本两阶段锁定的资金移动执行器——initiate（找/建腿+挂锁）/ settle（post+补记+腿收口，3× 重试）/ voidAttempt / rebuild（新 attempt 新单，历史留档）；充值三弧首个消费者，提现/兑换按同一图纸复用
- 执行引擎 `funds-orders/funds-order.service.ts`：`create()`（挂父单+腿号，初态按资产类型）｜ `advance()/advanceByNo()`（逐步推进+记账+生效日透传）｜ `findNonTerminalByWallet()`（对账在途识别）｜ `resolveExternalRef()/buildExternalRefPatch()`（参考号统一铸/读）
- 迁移表 `constants/funds-order-transitions.constant.ts`（四套 + `getTransitionMap()`）；方向判定 `directionOf()`（父 FK + 腿号：充值腿 1=入金、腿>1=内部；提现=出金；兑换=内部）
- 消费方分流：`deposit-workflow.service.ts → handleFundsOrderChanged()`（腿 1/2/3/4 各自 handler）；`withdraw-workflow` 本金/费腿分流；腿收口 `clearDispositionLeg()` + 守则测试（扫全部 settle* 必含收口调用）
- 参考号铸造 `common/utils/fake-external-refs.util.ts`（演示假值，见 demo/simulated-externals）
- admin `funds-orders.admin.controller.ts` + `FundsOrderList/Detail.tsx`（⚡模拟推进 + 推单按钮）
