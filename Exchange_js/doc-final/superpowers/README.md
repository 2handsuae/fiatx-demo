# ⚠️ superpowers —— 历史 / 设计存档层（非活真相源）

它记录"当初怎么设计的"，**不代表代码现状**。

- **看当前现状** → [`../reference/truth/`](../reference/truth/)
- **看写法约束** → [`../rules/`](../rules/)
- **看技术债** → [`../BACKLOG.md`](../BACKLOG.md)

| 目录 | 内容 |

## 写入规范

新 spec / plan 继续写这里，命名 `YYYY-MM-DD-<topic>[-design].md`。
⚠️ superpowers 技能**默认**把 spec 写去 `docs/superpowers/specs/`——**本项目覆盖此默认**，务必落在本目录（`doc-final/superpowers/`），且在 `Exchange_js/` 目录下运行、勿从仓库根 `重做版/` 跑。详见根目录 `CLAUDE.md`。
