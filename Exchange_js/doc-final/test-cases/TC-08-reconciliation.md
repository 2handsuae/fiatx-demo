# TC-08 · 对账（Reconciliation）测试用例

> 对应 PRD《8. 对账（Reconciliation）》v2.0 ｜ 域码 `REC` ｜ 34 条
> 口径与排除范围见 [README.md](README.md)

**本篇排除**：FR-11 / AWAITING「待外部数据」（G4，stub 未做）；人工强推腿（G1，本期不作交付）；破账与抵销错误的处置闭环（G2）；INTERNAL_BREAK 事故界面/告警/更正（G3）；对账状态结转 `reconciliationStatus`（G5）；aging / SLA / maker-checker（G6）；VARA 通报 / ≥8 年留存 / 报告导出（G9）。
**触发方式说明**：外部账单生产摄入未做（G4），用例以 demo 注入的外部余额 / 外部流水作为外部侧数据源。
