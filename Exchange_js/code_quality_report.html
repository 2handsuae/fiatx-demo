1. 执行摘要

本项目是一个基于 NestJS 和 React 的交易所/资产管理系统。整体架构设计合理（模块化程度高），但在代码规范执行、测试覆盖率以及前端工程化方面存在显著问题。特别是核心业务流程的测试通过率较低，且前端代码中存在多处硬编码和潜在的运行时错误。

2. 关键问题 (Critical)

问题描述位置影响
根目录测试文件夹缺失 / (Root) 导致 E2E 测试无法运行，项目结构不完整。
前端未定义函数引用 admin-web/src/pages/DepositTransactionList.tsx 点击复制按钮会导致应用崩溃（copyToClipboard 未定义）。
测试通过率极低 (44%) src/modules/**/*.spec.ts 核心业务逻辑（如支付状态转换）缺乏有效验证。

3. 重要问题 (Important)

  • 硬编码 API 地址: 发现 62 处硬编码的 http://localhost:3000，将导致生产环境部署失败。
  • 代码重复: SwapTransactionsService 和 DepositTransactionsService 中的编号生成逻辑完全一致，缺乏抽象。
  • Prisma 版本落后: 当前版本 5.22.0，最新版本 7.3.0，存在潜在的性能和安全性优化空间。
